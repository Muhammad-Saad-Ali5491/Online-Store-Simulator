# 🛒 Online Store Simulator

This project is a simple **Online Store Simulator** developed in C++. It demonstrates core functionalities of an e-commerce platform, such as user registration, login, product browsing, cart management, and order placement. The project is designed using **Object-Oriented Programming (OOP)** principles and showcases modular, reusable, and maintainable code.

---

## 🚀 Features

- User Registration and Login
- Product Catalog Management
- Shopping Cart Functionality
- Order Processing
- Basic Input Validation
- File-based Data Storage (Optional)

---

## 🛠️ Tech Stack

- **Language:** C++
- **Paradigm:** Object-Oriented Programming (OOP)
- **Compiler:** Any C++11 compatible compiler (e.g., g++, Visual Studio, Code::Blocks)

---

## 🧱 Project Structure

```
📁 Online-Store-Simulator
├── main.cpp                  # Entry point of the application
├── User.h / User.cpp         # Handles user-related functionality
├── Product.h / Product.cpp   # Product definitions and management
├── Cart.h / Cart.cpp         # Shopping cart management
├── Order.h / Order.cpp       # Order processing logic
└── README.md                 # Project documentation
```

---

## 🧑‍💻 How to Run

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Muhammad-Saad-Ali5491/Online-Store-Simulator.git
   cd Online-Store-Simulator
   ```

2. **Compile the project (using g++):**

   ```bash
   g++ main.cpp User.cpp Product.cpp Cart.cpp Order.cpp -o store
   ```

3. **Run the simulator:**

   ```bash
   ./store
   ```
